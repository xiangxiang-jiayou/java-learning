| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| 0 准备期 | 环境搭建、Git、Maven | 进行中 |
| 1 语言基础 | 语法、面向对象、常用类 | 未开始 |
| 2 核心进阶 | 集合、泛型、IO、反射、Stream | 未开始 |
| 3 并发与 JVM | 线程、锁、线程池、GC | 未开始 |
| 4 数据存储 | MySQL、Redis | 未开始 |
| 5 主流框架 | Spring / Spring Boot / MyBatis | 未开始 |
| 6 分布式与中间件 | MQ、ES、Spring Cloud | 未开始 |
| 7 工程化与上线 | Docker、Nginx、CI/CD、监控 | 未开始 |
| 8 面试冲刺 | 简历、八股、算法 | 未开始 |
