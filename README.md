# Java 学习记录

## 目录结构

```text
src/     最早的零散练习：Hello World、数组、键盘输入、圆面积
day5/    面向对象入门：类与对象、this 关键字
day6/    封装、JavaBean、static 成员与静态方法、电影信息管理小案例
day7/    继承与多态：extends、方法重写、构造器、多态、会员卡案例
day8/    抽象类、接口、final、枚举、单例，以及智能家居综合案例
array/   数组相关练习
```
